# Company Engineering Knowledge

This directory contains read-only internal engineering documentation available
to the Enterprise Developer Assistant.

Keep documents factual, reviewed, and written for their intended engineering
audience. Do not place secrets, API keys, personal data, or confidential
credentials in this directory.

## Structure

- `architecture/`: system diagrams, service boundaries, data flows, and
  architecture decision records.
- `api-documentation/`: API conventions, schemas, integration guides, and
  endpoint documentation.
- `runbooks/`: operational procedures, troubleshooting guides, and recovery
  instructions.
- `coding-standards/`: language-specific conventions, review standards, and
  repository development guidelines.

## Document guidance

Use Markdown, preserve descriptive filenames, include an owning team or
maintainer, and update documents alongside relevant architecture or code.
Relative links should remain inside this directory. The Filesystem MCP server
restricts access to this directory and runs in read-only mode.
